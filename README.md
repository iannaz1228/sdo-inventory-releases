# SDO Inventory — Releases

Installers for **SDO Inventory**, the offline inventory and property management system of the
Schools Division Office of Iriga City.

## Install or update

1. Open the [latest release](https://github.com/iannaz1228/sdo-inventory-releases/releases/latest).
2. Download `SDOInventory-Setup-<version>.exe` and run it on the Windows PC.
3. Your inventory data is kept when you update.

The app's **Help → Check for Updates** finds new releases here automatically when the PC is online.
The administrator can download and install from inside the app; the installer is checked against
its SHA-256 checksum (listed in `sdo_inventory_update.json`) and a backup is made first.

SDO Inventory itself works fully offline. This repository contains release files only.
